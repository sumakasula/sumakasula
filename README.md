## 🟣 Featured Projects

<details>
<summary><b>🚦 Traffic Sign Recognition for Self-Driving Cars</b></summary>

<br/>

A deep learning system built on a **Neural ODE + ResNet-18 hybrid architecture** to classify 43 traffic sign categories from the GTSRB dataset, deployed as a real-time Flask web application with live camera integration.

| Attribute | Details |
|---|---|
| **Stack** | Python, PyTorch, ResNet-18, Neural ODE, Flask, OpenCV |
| **Scale** | 50,000+ GTSRB images across 43 traffic sign classes |
| **Performance** | 98.25% training accuracy, 90.06% test accuracy; converged in 30 epochs using AdamW + mixed precision |
| **Security** | Local inference only, no external data transmission from camera feed |
| **Impact** | Outperformed standalone Neural ODE by ~12% and VGG-16 by ~15% in test accuracy across 6 benchmarked architectures |
| **Repository** | [Traffic-Sign-Recognition](https://github.com/sumakasula) |

Benchmarked against six candidate architectures, the hybrid model combined the continuous-depth representation power of Neural ODEs with the feature extraction strength of ResNet-18, then shipped as a real-time inference app rather than a static notebook result.

</details>

<details>
<summary><b>🍽️ Optimizing Restaurant Performance</b></summary>

<br/>

A machine learning system combining regression and time-series forecasting to predict customer bills and forecast next-day revenue, paired with an automated reservation-eligibility engine.

| Attribute | Details |
|---|---|
| **Stack** | Python, Linear Regression, ARIMA, Pandas, Scikit-learn |
| **Scale** | Full restaurant transaction and reservation dataset across 3 peak time slots |
| **Performance** | R² = 0.99 on bill prediction; 98% accuracy on time-spent prediction |
| **Security** | Aggregated transactional data, no customer PII exposed |
| **Impact** | Forecasted ₹5,07,028 in next-day revenue; identified 15–20% higher bills from reserved & 8-person groups; proposed 6 strategies projected to improve table turnover by ~30%, cutting manual reservation effort by ~40% |
| **Repository** | [Optimizing-Restaurant-Performance](https://github.com/sumakasula) |

Beyond the modeling, the project translated statistical findings — like which guest segments reliably spend more — into concrete, business-ready operational recommendations.

</details>

<details>
<summary><b>💧 Drinking Water Access Prediction — IBM Auto AI</b></summary>

<br/>

An end-to-end ML pipeline built during an AI & Cloud Technologies internship, using **IBM Watson Auto AI** to predict access to drinking water across 36 Indian states from 666+ survey data points.

| Attribute | Details |
|---|---|
| **Stack** | Python, IBM Watson Auto AI, IBM Cloud, XGBoost, Jupyter Notebook |
| **Scale** | 666+ survey data points across 36 Indian states |
| **Performance** | R² score of 0.941 using an AutoAI-selected XGBoost Regressor |
| **Security** | Read-only survey data, no sensitive PII |
| **Impact** | Identified Gender, State, and Sector as top predictors; surfaced rural water access as low as 26.5%, informing targeted-intervention recommendations |
| **Repository** | [drinking-water-analysis-autoai](https://github.com/sumakasula/drinking-water-analysis-autoai) |

Rather than stopping at model accuracy, the project visualized rural–urban access disparities to make the case for where intervention would have the highest impact.

</details>
